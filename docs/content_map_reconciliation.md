## この表の読み方

- content.yaml の各値が、**どの転記元のどの文からできたか**を1行ずつ示す。
- **種別**の凡例:
  - **逐語** … 原文のまま（先頭の「・」記号と改行の除去のみ）
  - **分割** … 長文セル・列挙文を個別項目へ分けた（順序は保持、文言は原文のまま）
  - **短縮** … ラベル化のための助詞落とし・囲み括弧はずしなど（文字の追加なし）
  - **省略[数値]** … 診断の重みの数値（尤度比・感度特異度・κ）を含む文・語句を載せなかった。必要箇所は「（数値はガイド第6章／bedside-bayes 参照）」に置換
  - **組み立て** … 転記元が疾患別・項目別になっていないものを、この表に示す根拠で疾患・項目へ割り付けた（文言は原文のまま）
  - **新規UI文言** … 転記元に対応する文がない新規起草。末尾の別枠にまとめた
  - **⚠要判断** … 転記ルールの適用に判断が入った箇所。副院長の裁定を仰ぐ
- 転記元の表記:
  - ガイド＝`docs/education/呼吸器身体診察実践ガイド_2026_統合版.docx`（python-docx の tables[n]／paragraphs[n] 番号）
  - 別冊＝`docs/education/肺エコー図譜_2026.docx`
  - profile表＝`scripts/build_lung_us_figures.py` L713〜L719（＋L735〜L742 の注記）

### exam_items 転記の共通規則（全疾患に適用）

1. 「典型的所見」セルの各箇条書き（・）を1項目に分割（**分割**）。先頭の「・」は除去。
2. 箇条書き全体を囲む（）は、ラベル化のため外した（**短縮**。例:「（緊張性では気管偏位）」→「緊張性では気管偏位」）。
3. **「注意点」列（行レベル）の置き場所**: 特定の所見を名指しする注意はその項目の note へ、群全体にかかる注意は**その群の先頭項目の note** へ置いた（群レベルの欄がスキーマにないため。複写はしない）。どの項目に置いたかは各表に明記。**この配置規則自体が組み立てであり、承認対象。**
4. priority: true は、その疾患の 🚑 30秒ルート段落（「まず探すN所見」）に**その所見が現れる**もの（番号つき所見・後続文の重症化サインとも）。
5. note 内の「／」は複数の転記元断片の連結子（原文には無い）。

## §16 定量の問いテンプレ4本と JVP の POCUS 手順（v1.3.0・2026-08-09 副院長承認）

**経緯。** 既存のテンプレは6本とも定性（あるか・ないか）だった。定量の型は v1.2.0 で実装済みだが、
テンプレが1本も無かったため、数値の問いは手書きするしかなかった。副院長の指示で、
**4病態に定量テンプレを1本ずつ**足す。当初案の6本から一息語数（COPD）と奇脈（喘息）は落とした
── 答え合わせの相手がエコーではなく別の実測（数える・血圧計）になり、
「画像を開く前に書く」という本アプリの骨格から外れるため（副院長判断）。

**数値は1問につき1つに留める。** 当初案は肺炎を「縦＝肋間・横＝cm」の2値にする構想だったが、
2値にすると集計の系統が割れて自分の尤度比が出しにくくなる（副院長判断）。
代わりに**問い文へ「どこで測るか」を書き込んで手技を固定**した。測る線がぶれる人は、
癖（平均ずれ）ではなくばらつき（SD・RCV）が大きく出る ── 手技の粗さが数字に現れる設計。

### 16.1 追加した4本（quick_templates.questions）

| 病態 | 文言 | 単位 | 根拠 |
|---|---|---|---|
| pneumonia | ◯下肺の実質化は、腋窩中線で何肋間ぶんの高さか | 肋間 | 副院長承認（2026-08-09） |
| effusion | ◯胸水の上縁は、腋窩中線で第何肋間の高さか | 肋間 | 同上。**肋骨番号ではなく肋間**にしたのは QUANT_UNITS の語彙内に収めるためと、POCUS がプローブを肋間に置いて上下させる手技だから |
| pneumothorax | ◯肺の虚脱は、鎖骨中線で第何肋間まで及ぶか | 肋間 | 同上（lung point） |
| hf | 頸静脈の拍動上縁は、胸骨角の上何cmか | cm | 同上 |

**なぜ体表からの cm でなく肋間か（胸水）。** 副院長の指摘 ── CT は両手挙上で撮影するので、
肩甲下角のような体表ランドマークは診察時と位置が変わる。文献を当たったところ、
検証済みの胸水量推定は**どれも体表からの高さを使っていない**（Balik 2006 PMID 16432674 は
後腋窩線でプローブを上下させ胸膜間の最大距離 Sep で V=20×Sep、r=0.72／Usta 2010 PMID 19903687 は
横隔膜中央からの距離 D で V=16×D／Ibitoye 2018 PMID 29228764 は4式比較で坐位式が最良 r=0.81）。
**肋間の番号は上肢の挙上で動かない。** 上肢挙上による体表ランドマークのずれを実測した研究は
3通りの検索で見つからず、根拠は解剖学的推論と副院長判断であることを明記しておく。

### 16.2 JVP の POCUS 手順（hf 定量テンプレの howto・新規医学文言）

**承認: 2026-08-09、副院長が手順の全文を確認のうえ「宜しくお願いします」。**

視診の「拍動上縁」とエコーの「虚脱点」は同じ物理点（静脈内圧が大気圧と釣り合う高さ）なので、
同じ物差し（胸骨角からの垂直距離）で並べられる。**POCUS には虚脱点の同定だけをさせ、
+5cm 換算は持ち込まない**（胸骨角と右房中心の垂直距離は体位で変わる ── Cook & Simel 1996、
ガイド文献99）。

出所の切り分け ── **Xing 2015（PMID 25904575 / doi:10.1161/CIRCIMAGING.114.003085）が検証したのは
「虚脱点と右房中心の高さの差」＝非侵襲CVP**（76例118測定、r=0.90／0.93、Bland-Altman 平均差
0.22／−0.09 mmHg）であって、胸骨角基準ではない。本アプリの手順は**虚脱点を同定する部分だけを借り**、
記録はガイド 3.5 の既存の物差しに揃えたもの。**この組み合わせ自体を検証した研究は無い**ため、
中心静脈圧の絶対値を出す方法ではなく、自分の視診を較正する物差しとして位置づける。
